# 5-Day Study Plan

---

## Day 1: Foundation
**Focus:** Technical glossary + Spotify intel brief

- [ ] Read `01-technical-glossary.md` -- internalize every term
- [ ] Read `04-spotify-intel-brief.md` -- memorize key system names (ML Home, Backstage, Honk, vLLM)

## Day 2: Product Case Framework
**Focus:** Framework + first 2 practice cases

- [ ] Read `03-product-case-framework.md` -- memorize the 7 steps
- [ ] Practice Case 1 (Centralized LLM Observability) out loud, 35-min timer
- [ ] Practice Case 2 (LLM Evaluation Framework) out loud, 35-min timer
- [ ] After each case, check: Did you use DIBB? Did you mention Golden Path? Did you propose design partner squads?
- [ ] Record yourself if possible -- listen back for filler words, pacing

---

## Day 3: More Cases + Deeper Tech

## Key Phrases to Have Ready

These should roll off your tongue naturally:

1. "I'd frame this as a bet using DIBB..."
2. "Golden Path approach -- make the right thing the easy thing"
3. "Co-design with a design partner squad"
4. "Think It phase to de-risk, then Build It with an MVP"
5. "Similar to how the Honk team approaches this..."
6. "Discoverable through Backstage"
7. "Python first, since that's where most ML practitioners live"
8. "Build on OpenTelemetry for vendor-neutral instrumentation"
9. "At Agility, I built something similar when..."
10. "At Bell, I faced a comparable challenge when..."
